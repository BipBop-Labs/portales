# Adding a website

1. Create `websites/<site>/AGENTS.md` from the website template.
2. Observe one safe browser path.
3. Add a page card for each page actually observed.
4. Add one flow that links those pages.
5. Replay it once deterministically.
6. Mark any unverified branch as provisional.
7. Check every relative link and scan the complete diff for private data.

Do not begin by writing a framework, scraper, API client, fixture library, or exhaustive test suite. Start with the smallest useful map.
